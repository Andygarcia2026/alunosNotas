# Sistema de Notas - Alunos

Projeto em Java que lê um arquivo `AlunosNotas.txt` e calcula a média final do aluno.

### Funcionalidades
- Busca aluno pelo nome digitado
- Lê 5 notas do arquivo TXT
- Solicita 2 notas de recuperação
- Calcula média final e verifica aprovação (média >= 7)

### Como rodar
1. Coloque o arquivo `AlunosNotas` na pasta `src/`
2. Rode o `Main.java`

### Tecnologias
Java, Files API, Scanner
